# Module 3 - Connect Observability

## Objective
Connect the agent to the signal sources it needs to investigate incidents.

## Suggested lab steps
1. Verify Application Insights is connected.
2. Verify Azure Monitor / alert rules are configured.
3. Optionally connect a code repository.
4. Optionally connect an incident system.
5. Validate that the agent can reason over recent telemetry.

## Example participant prompts
- What changed recently in this application?
- Are there exceptions correlated with failed requests?
- Which resources appear most impacted?
