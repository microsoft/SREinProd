# Module 5 - Incident Drill

## Objective
Run a realistic incident and let the agent investigate and propose remediation.

## Suggested lab steps
1. Run the warmup script.
2. Inject the fault.
3. Wait for telemetry and alerts to appear.
4. Ask the agent to investigate.
5. Review the evidence chain and root cause.
6. Approve or discuss remediation.
7. Validate recovery.
8. Capture the incident summary.

## Success criteria
- participants can see the fault appear in telemetry
- the agent identifies a plausible root cause
- remediation is proposed safely
- the environment is restored after the exercise
