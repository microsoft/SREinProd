# Module 2 - Deploy the Agent

## Objective
Deploy a working Azure SRE Agent and attach it to the workshop environment.

## Suggested lab steps
1. Sign in to the Azure SRE Agent portal.
2. Create a new agent.
3. Place the agent in a dedicated resource group.
4. Attach the workshop application resource group.
5. Verify the agent identity exists.
6. Assign required RBAC.
7. Confirm the agent can see the monitored resources.

## Validation checklist
- agent resource exists
- monitored resource group is attached
- required permissions are assigned
- the agent can answer a basic question about the environment
