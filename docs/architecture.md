# Architecture (proposed)

## Demo environment
- Demo application (App Service or Container Apps)
- Application Insights
- Azure Monitor alerts
- Azure SRE Agent
- Optional code repository connection (GitHub / Azure DevOps)
- Optional incident platform integration

## Core learning outcome
Participants should understand that SRE Agent is not just a chat surface. It becomes useful when it has:
1. telemetry
2. operating context
3. response plans
4. permissioned action paths
